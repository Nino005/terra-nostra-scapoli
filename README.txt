TERRA NOSTRA — VERSIONE 2
==========================
Rifacimento completo del sito.

Aggiunte:
- tutte le nuove fotografie fornite dall'utente: antipasto, pasta, pizza, ravioli e sala;
- menu completo in HTML senza prezzi, ricavato dal PDF fornito;

La fotografia della zampogna nella sezione dedicata è caricata dal sito del Museo Internazionale della Zampogna di Scapoli.
